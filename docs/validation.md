# 验证记录

本项目在本地 MySQL 8.0.44 上完成了历史数据初始化、API 增量导入、重复执行检查和 Dashboard 生成。以下结果来自 2026-10-20 的实际运行。

## 数据结果

| 项目 | 结果 |
| --- | ---: |
| 历史 CSV 文件 | 365 |
| 历史 Raw / Clean | 1,825 / 1,825 |
| API Raw | 80 |
| 最终 Raw / Clean | 1,905 / 1,905 |
| Clean 唯一业务键 | 1,905 |
| 五城市记录数 | 每个城市 381 |
| 数据日期范围 | 2025-01-01 至 2026-10-19 |
| 包含缺失值的记录 | 67 |
| 质量问题 | 469 |

历史数据中有 20 条记录因为 23 时没有目标指标而使用了当天更早的可用小时。缺失字段保持为空，没有使用其他小时或统计值填充。

## 重复执行和增量

历史批次连续导入并执行两次 ETL 后，Raw、Clean、业务唯一键和质量问题数量均未增长。

API 增量第一次执行时，每个城市新增 2 个业务日期，并与已有 API 数据重叠 12 天；第二次执行时每个城市新增 0 条、重叠 14 条。最终 API 来源键保持 80 个且全部唯一。

## 报告输出

报告由实际 MySQL 数据生成，包含：

- `dashboard.html`
- `clean_air_quality.csv`
- `quality_issues.csv`
- `city_summary.csv`
- `monthly_summary.csv`
- `report.md`

`monthly_summary.csv` 包含 13 个月 × 5 个城市共 65 行，记录数合计为 1,905，与 Clean 层一致。Dashboard 的七张图表在桌面和 390px 窄屏下完成浏览器检查，控制台没有 error 或 warning。
