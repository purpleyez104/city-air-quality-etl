# 数据来源说明

项目使用两类数据：QuotSoft 提供的历史城市空气质量 CSV，以及中国环境监测总站候选接口返回的近期数据。两类来源统一转换为五城市日粒度记录，但在 Raw 层保留各自的来源信息。

## 历史 CSV

数据下载页面：[QuotSoft 全国空气质量历史数据](https://quotsoft.net/air/)。页面说明数据来自中国环境监测总站，城市平均数据文件采用 `china_cities_YYYYMMDD.csv` 命名，结构为 `date / hour / type / 各城市`。

本项目使用的 2025 年数据具有以下特征：

- 365 个有效 CSV，日期连续覆盖 `2025-01-01` 至 `2025-12-31`。
- 每个文件包含 378 列，均能找到北京、上海、广州、成都和武汉。
- 总文件大小为 136,564,155 bytes，整体 SHA-256 为 `ef9234d670e85c9751f36913cc141f2caabc98b0bd924b5ceb94c1617ecbc406`。
- 转换后得到 1,825 条日记录；其中 20 条使用了 23 时之前的可用小时，469 个字段为空。
- 两个以 `._` 开头的系统元数据文件不参与导入。

QuotSoft 页面允许将数据用于分析和研究，但没有发现明确的开源再分发 License，因此原始 CSV 不提交到 Git。

## API 数据

接口请求格式参考了旧项目 `D:\Projects\AQADR`，随后重新验证了城市代码、响应字段和日期格式。旧项目仅用于只读参考，其代码、虚拟环境、缓存和输出均未复制到本仓库。

2026-10-18 对五个城市各执行了一次请求，每个城市返回 14 条记录，共 70 条，日期覆盖 `2026-10-04` 至 `2026-10-17`。2026-10-20 再次采集时，每个城市新增 `2026-10-18` 和 `2026-10-19` 两天数据。最终 API Raw 层共有 80 条记录。

每次成功请求都会保存原始 JSON 和 Manifest。Manifest 记录批次、请求时间、城市、记录数、文件大小和 SHA-256；非 JSON、字段不完整、响应过大或请求失败的数据不会进入 MySQL。

## 字段和限制

历史 CSV 的污染物单位按 QuotSoft 页面说明解释。当前 API 没有可靠的字段字典，响应中的 `Measure` 实际为人群活动建议而非计量单位，因此项目不为 API 污染物字段标注单位。

上游 API 返回顺序不稳定，程序不会依赖响应顺序进行去重或选择记录。候选接口的长期可用性和访问限制仍不能由本次成功请求保证。

真实 CSV、API 响应和数据库备份均保存在 Git 忽略目录。仓库只包含用于自动化测试的最小脱敏样例。
