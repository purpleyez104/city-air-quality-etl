# 实施计划

项目按下面的顺序完成：

1. 保存并校验五城市 API 响应，生成 JSON 和 Manifest。
2. 创建 MySQL 表，导入结构化原始数据。
3. 清洗字段、记录质量问题，并按业务键重复写入。
4. 校验 2025 年历史 CSV，转换并导入五城市日数据。
5. 合并 API 增量，处理日期重叠和来源优先级。
6. 生成 CSV、Markdown 和 Plotly Dashboard。
7. 使用自动化测试、数据库对账和浏览器检查验证结果。

## 验证方法

- 检查原始文件的 Hash、记录数和必要字段。
- 验证日期转换不依赖机器所在时区。
- 覆盖正常值、缺失值、越界值、重复业务键和未知来源。
- 对同一批数据执行两次，确认记录数量不重复增长。
- 对比 Raw、Clean、月度汇总和 Dashboard 的记录数。
- 检查桌面和窄屏下的图表布局。

## 当前进度

以上步骤已经完成。项目目前包含 2025 年历史初始化、2026 年 API 增量、MySQL Raw/Clean 处理、质量记录和静态 Dashboard。实际数据量与测试结果见 [验证记录](validation.md)。

本项目不计划加入 Airflow、Kafka、Spark、实时处理或其他基础设施；如果以后需要继续扩展，应先确定新功能对作品展示的实际价值。
